# 人物设定

## 主要角色

### 陈凡
- **年龄**：20岁
- **身份**：江城大学计算机系大三学生，家境贫寒
- **外貌**：身高175cm，体型偏瘦，穿着朴素，眼睛在获得超能力后闪烁着神秘光芒
- **性格**：坚强、隐忍、聪明、有仇必报
- **背景**：出生在江北省偏远小山村，父母为农民，哥哥辍学打工
- **遭遇**：被女友林诗雨抛弃，被周浩然羞辱，获得红线眼超能力后开始复仇
- **能力**：红线眼（能看到人与人之间的性关系连接）

### 林诗雨
- **年龄**：20岁
- **身份**：江城大学计算机系大三学生，班花
- **外貌**：身高165cm，长相甜美，长发飘飘，喜欢穿性感衣服
- **性格**：虚伪、拜金、势利、善于伪装
- **背景**：出身于普通家庭，但一直想通过婚姻改变命运
- **关系**：与多个男人有过关系，包括周浩然、张总等
- **行为**：经常出入高端场所，喜欢和有钱男人交往

### 周浩然
- **年龄**：20岁
- **身份**：江城大学计算机系大三学生，校草
- **外貌**：身高185cm，相貌英俊，穿着时尚，经常开豪车上学
- **性格**：嚣张跋扈、目中无人、虚伪、花心
- **背景**：父亲是江城房地产开发商，身家过亿，母亲是江城市第一人民医院医生
- **关系**：与林诗雨、李梦等多个女生有过关系
- **行为**：经常欺负普通同学，生活放荡不羁

## 次要角色

### 天涯浪子
